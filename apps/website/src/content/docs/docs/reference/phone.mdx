# Phone

```ts
import { isPossibleNepalPhone, isValidNepalPhone, parseNepalPhone, formatNepalPhone } from 'nepali-toolkit/phone';

isPossibleNepalPhone('9841234567'); // true for a valid phone shape
const phone = parseNepalPhone('+977 9841234567');
isValidNepalPhone(phone);
formatNepalPhone(phone);
```

Validation helpers distinguish possible, allocated, and valid numbers and expose `getNepalPhoneType`. `isSameNepalPhone` compares normalized values. Formatting is controlled by `PhoneFormatOptions`; `metadataRevision` identifies the phone metadata revision used by the package.

Malformed values throw `InvalidPhoneError` in parsing and formatting APIs. Validation helpers return booleans for normal invalid input.
