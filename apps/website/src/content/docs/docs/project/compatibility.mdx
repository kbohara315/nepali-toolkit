# Compatibility

The toolkit is pure TypeScript and publishes ESM and CommonJS builds. It has zero runtime dependencies and is designed for Node, browsers, and bundlers that support the published module formats.

Civil date functions do not depend on browser globals or the machine timezone. The website itself is a static Astro build and the playground runs browser-safe utilities on the client.

The package is early development. Verify the package version and your runtime's module support before adopting it in a long-lived application.
