# Build for Nepal. With less code.

`nepali-toolkit` is a TypeScript-first collection of dependency-free utilities for dates, numbers, NPR currency, land units, words, phone numbers, Nepali text, and Nepal's administrative hierarchy.

## Start here

- [Getting started](./getting-started/) installs the package and makes a first useful call.
- [The playground](../../playground/) lets you try real package APIs in your browser.
- [Imports and bundling](./guides/imports-and-bundling/) explains the explicit subpath contract.

## Domains

Browse the [date](./reference/date/), [number](./reference/number/), [currency](./reference/currency/), [land](./reference/land/), [words](./reference/words/), [collation](./reference/collation/), [phone](./reference/phone/), and [admin](./reference/admin/) references.

:::note
The package is in early development. APIs may change before `1.0.0`.
:::
