Nepali Toolkit provides JavaScript and TypeScript utilities for applications built for Nepal. Import only the features you need. [Install the package](./getting-started/) or try the [playground](../playground/).

## Find a guide for your task

- [Convert dates and build calendars](./guides/dates-and-calendars/): date-only values, dates in a timezone, parsing, and arithmetic.
- [Format exact money and number words](./guides/exact-money-and-words/): decimal strings, bigint paisa, and consistent written totals.
- [Validate Nepal phone input](./guides/phone-validation/): normalization, shape, allocation, and display.
- [Convert land measurements](./guides/land-conversions/): hill/Terai units, metric values, and display precision.
- [Sort and search Nepali text](./guides/nepali-sorting-and-search/): deterministic ordering and normalized matching.
- [Build administrative address selectors](./guides/administrative-data/): linked province/district/palika lists, ward checks, name search, and postal codes.
- [Handle errors and external input](./guides/errors-and-input/): validate form values and handle error codes.
- [Choose imports and control bundles](./guides/imports-and-bundling/): focused entrypoints and module formats.
