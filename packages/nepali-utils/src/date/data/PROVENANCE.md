# Data provenance

The Patro month-length dataset is a working transcription (`sourceRevision:
working-2026-08-22`). It is functional but has not completed the
publication-level provenance review and independent conformance gating
described in the migration blueprint. Do not present supported-range or
correctness claims beyond what the conformance vectors demonstrate.

Regenerate runtime data with `pnpm generate:date` and check determinism
with `pnpm verify:date`.
